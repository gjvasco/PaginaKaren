Falta conectar Supabase

Para usar el panel externo del blog:

  1. Crea un proyecto gratuito en supabase.com.
  2. Abre el SQL Editor de Supabase, pega el contenido de supabase-setup.sql y ejecútalo.
  3. En Authentication → Users, crea tu usuario y contraseña.
  4. En Project Settings → API, copia tu Project URL y anon public key en supabase-config.js.
